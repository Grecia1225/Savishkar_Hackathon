# Problem Statement
Many citizens are unaware of government welfare schemes they are eligible for. 
Information is scattered across multiple websites, making it difficult and time-consuming to find relevant schemes. As a result, deserving individuals often miss out on benefits.
# Proposed Solution
SchemeSathi is a web application that simplifies this process by collecting basic user details such as age, income, category, and occupation, and automatically filtering eligible government schemes. 
The system presents relevant schemes with benefit details and direct application links, making access to welfare programs faster, easier, and more inclusive.
